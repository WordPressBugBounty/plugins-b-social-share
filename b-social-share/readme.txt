### Why Social Share Block?

Share your website or pages on social networks and messaging apps with a solution built for the modern WordPress editor. **Social Share Block** is lightweight and Gutenberg-native, designed to boost your social signals without the bulky scripts that bloat your page.

You get full control over how your share buttons look – colors, sizes, layouts, backgrounds, and shadows. Whether you need a simple row of icons or a vertical column, you can set it up in seconds from the block sidebar, or drop the buttons anywhere with a shortcode.

### Free Features

- **4 Free Share Themes:** Ready-made button styles you can apply in one click.
- **Popular Social Networks:** Share to the networks and mobile messengers your audience actually uses.
- **Row or Column Layouts:** Choose the layout direction that fits your design.
- **Full Style Control:** Customize icon size, color, background color, box-shadow, and borders.

### How to Use – Quick Start

1. Install and activate the **B Social Share** plugin.
2. In the Gutenberg editor, add the **Social Share** block from the "Widgets" block category.
3. Pick a theme and adjust colors, sizes, and layout from the right-side settings sidebar.

== Installation ==

**From your WordPress dashboard (recommended):**

1. Go to **Plugins → Add New**.
2. Search for **"B Social Share"**.
3. Click **Install Now**, then **Activate**.
4. Add the **Social Share** block to any post or page from the Gutenberg editor.

**Manual installation:**

1. Download the plugin ZIP file and upload the folder to the `/wp-content/plugins/` directory (or upload the ZIP via **Plugins → Add New → Upload Plugin**).
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Add the block from the Gutenberg editor, or use the shortcode in any page or widget.

== Frequently Asked Questions ==

= Is Social Share Block free? =
Yes, Social Share Block is a free Gutenberg block plugin. A Pro version adds a floating share bar, share locker, click to chat, and more engagement blocks.

= Does it work with any WordPress theme? =
Yes, it works with any standard WordPress theme.

= Can I change the block settings? =
Yes, you can change all block settings – theme, layout, colors, icon size, shadows, and borders – from the Gutenberg editor's right sidebar.

= How many times can I reuse the block? =
There is no limit – you can use the block as many times as you want, on as many pages as you want.

= Will the share buttons slow down my website? =
No. The plugin is lightweight and optimized for speed – it is built for the modern block editor without the bulky scripts that bloat pages.

= Can I add social sharing buttons without Gutenberg? =
Yes. The plugin supports shortcodes, allowing you to place social sharing buttons in supported WordPress areas outside the standard block editor workflow.

= Can I create floating social share buttons? =
Yes. The Pro version includes a Floating Share Bar that can remain visible while visitors scroll.

= Can I add share buttons outside the block editor? =
Yes. Shortcode support lets you place share buttons in any page, post, or widget.

= Can visitors share selected text from my website? =
Yes. The Pro Highlight to Share block allows visitors to select text and share it using a floating sharing tooltip.

= Can I add a QR code for sharing a WordPress page? =
Yes. The Pro QR Code Share block generates a scannable QR code for sharing the current page.


= Can I customize the look of the share buttons? =
Yes. You can choose from ready-made themes, switch between row and column layouts, and customize icon size, colors, background, box-shadow, and borders.

= Where can I get support? =
You can post your questions on the [support forum here](https://wordpress.org/support/plugin/b-social-share/).

### Build Instructions

To build the plugin from source, follow these steps:
1. Clone the repository or download the source code.
2. Navigate to the plugin directory.
3. Run `npm install` to install dependencies.
4. Run `npm run build` to build the production assets.

### File Mapping

To understand how the source code maps to the compiled assets, see the list below:
- `src/` - Source code for the Gutenberg block and admin interface.
  - `src/index.js` → `build/index.js` (Main block script)
  - `src/view.js` → `build/view.js` (Frontend script)
  - `src/shortcode/shortcode.js` → `build/shortcode.js` (Shortcode script)
  - `src/Admin/Dashboard.js` → `build/admin-dashboard.js` (Admin dashboard script)
- `build/` - Compiled and minified assets generated by the build process.
- `inc/` - PHP files for plugin functionality.
- `assets/` - Static assets like images and fonts.
